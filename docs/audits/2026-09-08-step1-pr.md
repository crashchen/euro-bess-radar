Continuous replay inferred one interval duration for an entire run, so a window containing five hourly days followed by one quarter-hour day could report €3,792 instead of €948 for the latter day. This change splits clean runs when daily cadence changes, preserving SoC carry while reapplying terminal neutrality at each segment end. The cockpit discloses actual cadence-driven splits.

Ordinary single-day and continuous DA/IDA replay now reject joins that lose rows from either market. Revenue two-stage dispatch checks coverage against both source days, preserving its existing 23/24 hourly IDA tolerance. Eleven existing solver price guards reject non-finite values through the established typed failure contract; four CSV importers drop non-finite required numeric rows with warning counts.

Validation and regression coverage:

- F1: high- and low-bias cases, standalone parity, physical throughput bound, complete day retention, cadence/gap/size-cap accounting, and caption constant plus real panel rendering.
- F2: both grid directions in ordinary replay, Revenue finer-IDA rejection, and sparse/NaN compatibility controls.
- F3: ±inf across solver price inputs, replay typed failures, all four importers, and IDA persistence/readback.
- 90 added cases: 86 fail against the baseline and 4 preserve existing behavior. No existing test was removed or rewritten. CC independently reproduced this split in a baseline worktree.
- Full suite: 1675 passed, 2 existing opt-in chart-render skips; separate slow suite: 21 passed. Ruff and `git diff --check` pass. CC independently reran the full suite with the same pass/skip counts and accepted the reviewed patch.

Scope and remaining work:

- F1 remains open for local-day-internal cadence changes in BG, EE, FI, GR, LT, LV, PT and RO. The FI joint-capacity diagnostic still returns €110.4375 instead of €114. Per-interval dt is a separate Step 2 change.
- F2 remains open in reserve ceiling, sequential, sequential reserve, stochastic and stochastic triple batch paths, plus the simplified Revenue uplift diagnostic. Step 1b will address these consumers before new features or Step 2.
- Actual cadence splits are counted; a data gap that already separates two runs does not increment the count. The count is not a general flag for every window spanning a resolution transition.
- No changes to dt inference, the regular-day guard, the 576-interval cap, failure status vocabulary, or DA market granularity. F4–F8 and README/Vault housekeeping retain their separate planned scope.

Detailed test mapping, before/after evidence and independent acceptance are recorded in `docs/audits/2026-09-08-step1-handoff.md`.
